## 0.2.0-alpha.1 — 2026-07-15

Engineering baseline for the greenfield LoanOS India platform.

- All 21 canonical lending journeys have governed product definitions, specialist services where applicable, shared schema-driven channel workspaces, and one evidence-bound composed lifecycle.
- Multi-tenant SaaS admission, provisioning, identity/staffing, revocation containment, audit attribution, agent governance and deterministic proxy integrations are executable.
- Release governance now supports typed human, AI-agent and service principals. AI agents are proposal-only and carry credential, installation, model, prompt and guardrail lineage; independent authenticated humans alone approve, promote and approve rollback.
- Rollback is a two-step authenticated proposal and independent approval workflow.
- Capability evidence is complete for all 463 catalogue entries; the canonical Node gate has 630 passing and 8 PostgreSQL-only skipped tests, with no failures. Rust workspace tests and lint, documentation integrity and website validation pass.

This is not a production or bank go-live release. The principal remaining gates are JD-05 generated full-stack/browser/PostgreSQL conformance for every journey, JD-01 product-administration completion, JD-06 live-provider and deployment certification, commercial workload identity for release agents, and institution-witnessed security/DR/UAT evidence.
